# Rodokmen Kříž – rodinný web

Stránky jsou chráněné heslem a zašifrované (AES-256-GCM, klíč z hesla přes PBKDF2); dešifrují se až v prohlížeči. Bez hesla jsou soubory nečitelné. Obsah se obnovuje každý večer z databáze projektu.

- `index.html` – rozcestník
- `strom.html` – Strom předků Sebastiana (zašifrováno)
- `arch.html` – Rodokmen – zdrojová databáze (zašifrováno)
